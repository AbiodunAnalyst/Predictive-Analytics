# Security policy

## Supported version

The current `main` branch is maintained as a portfolio and research demonstration.

## Reporting a vulnerability

Open a GitHub issue only for non-sensitive security observations. For anything involving credentials, private data or an exploitable vulnerability, contact the repository owner privately through the contact method listed on the GitHub profile.

Do not include secrets, confidential datasets, personal information or live exploit details in a public issue.

## Data and model safety

- Do not upload confidential operational records to the public deployment.
- Do not commit API keys, passwords or connection strings.
- Validate uploaded schemas, file size and expected data types.
- Treat model output as a technical demonstration, not a safety instruction.
